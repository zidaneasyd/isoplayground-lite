# Isometric World Engine — Level 1

## Menjalankan
Jalankan folder ini melalui server lokal karena menggunakan JavaScript ES Modules.

Contoh:
- VS Code: gunakan ekstensi Live Server.
- Node.js: `npx serve .`

Lalu buka alamat lokal yang diberikan server.

## Fondasi saat ini
- Canvas responsif dengan latar hitam.
- Grid dunia 20 × 20.
- Tile diamond 64 × 32.
- Permukaan abu-abu dengan garis grid abu-abu gelap.
- Konversi koordinat grid ke isometrik.
- Game loop, renderer, dan kamera dasar.

Kontrol kamera, zoom, terrain berbeda, objek, dan penyimpanan belum termasuk tahap ini.
